Kurulum kılavuzuSetup guide

WordPress sitenizi yapay zekâ aracınıza bağlayın Connect your WordPress site to your AI tool

Bu sayfa, daha önce hiç MCP kullanmamış birinin sıfırdan bağlanabilmesi için yazıldı. Terminal bilmeniz gerekmiyor; gereken her komut hazır veriliyor. Üç adım sürüyor, sonra aracınızı seçip yapılandırmayı kopyalıyorsunuz. This page is written for someone who has never used MCP. You don't need to know the terminal; every command you need is written out. It takes three steps, then you pick your tool and copy one config block.

Örnekleri kendi sitenize göre doldurunFill the examples in with your own site

Buraya yazdıklarınız sayfadaki tüm örneklere işlenir. Tarayıcınızdan çıkmaz, hiçbir yere gönderilmez. Parolanızı buraya yazmayın; ona sayfanın ihtiyacı yok. What you type here is written into every example on the page. It never leaves your browser and is sent nowhere. Do not type your password here — the page has no need for it.

MCP nedir, neden gerekiyor?What is MCP, and why do you need it?

Yapay zekâ araçları kendi başlarına sizin sitenize erişemez. MCP (Model Context Protocol), bir yapay zekâ aracının dışarıdaki bir sisteme bağlanıp orada iş yapabilmesi için ortak bir dildir. USB'nin cihazlar için yaptığını, MCP yazılımlar için yapar: bir kez konuşulan bir standart. AI tools cannot reach your site on their own. MCP (Model Context Protocol) is a shared language that lets an AI tool connect to an outside system and actually do things there. What USB did for devices, MCP does for software: one standard everyone speaks.

Bu depodaki köprü eklentileri, WordPress'in yapabildiklerini bu dile çevirir. Kurduğunuzda siteniz, aracınızın bağlanabileceği bir uç noktaya sahip olur. Bağlandıktan sonra aracınız ürün oluşturabilir, yazı düzenleyebilir, SEO ayarı değiştirebilir; sizin adınıza ve sizin izin verdiğiniz kadar. The bridge plugins in this repository translate what WordPress can do into that language. Once installed, your site gains an endpoint your tool can connect to. After that your tool can create products, edit posts, change SEO settings — as you, and only as far as your permissions allow.

KısacaIn short

Köprüleri kurdunuz → siteniz bir adres yayınlıyor → aracınıza o adresi ve bir parola veriyorsunuz → araç sitenizi kullanabiliyor. Bu sayfa ikinci yarısını anlatıyor. You installed the bridges → your site publishes an address → you hand that address and a password to your tool → the tool can use your site. This page covers the second half.

Üç adımThree steps

1

Bir uygulama parolası oluşturunCreate an application password

Aracınıza normal WordPress parolanızı vermezsiniz. Bunun yerine sadece o araç için, istediğinizde tek başına iptal edebileceğiniz ayrı bir parola üretirsiniz. You do not give your tool your normal WordPress password. Instead you mint a separate one for that tool alone, which you can revoke on its own whenever you like.

  1. WordPress yönetim panelinde Kullanıcılar → Profil sayfasını açın.In your WordPress admin, open Users → Profile.
  2. Sayfanın altındaki Uygulama Parolaları bölümüne inin.Scroll down to Application Passwords.
  3. Bir ad yazın; hangi araç için olduğunu yazmak işinizi kolaylaştırır, örneğin Claude Code.Type a name — naming the tool makes life easier later, e.g. Claude Code.
  4. Yeni Uygulama Parolası Ekle'ye basın ve çıkan parolayı kopyalayın.Press Add New Application Password and copy the value it shows.
DikkatCareful

Parola yalnızca bir kez gösterilir; sayfadan ayrılınca bir daha göremezsiniz. Boşluklu görünür (abcd EFGH 1234 …); boşlukları silmenize gerek yok, WordPress onları yok sayar. The password is shown once and never again after you leave the page. It appears with spaces (abcd EFGH 1234 …) — you don't need to strip them, WordPress ignores them.

Uygulama Parolaları bölümünü göremiyorsanız, siteniz büyük olasılıkla HTTPS üzerinden çalışmıyordur. WordPress bu bölümü o durumda gizler. If you can't see the Application Passwords section, your site is almost certainly not on HTTPS. WordPress hides the section in that case.

2

Uç noktanızı öğreninFind your endpoint

Adres her zaman sitenizin adresi artı sabit bir yoldur: The address is always your site address plus one fixed path:

MCP endpoint
https://bucagdas.com/wp-json/mcp/mcp-adapter-default-server

Bu adresi tarayıcıya yapıştırırsanız hata görürsünüz; bu normaldir. Uç nokta yalnız POST isteklerine yanıt verir, tarayıcı ise GET gönderir. Pasting that into a browser shows an error — that is expected. The endpoint only answers POST requests, and a browser sends GET.

Kalıcı bağlantılar “düz” iseIf your permalinks are “plain”

Ayarlar → Kalıcı Bağlantılar sayfasında “Düz” seçiliyse yukarıdaki adres çalışmaz. Bu biçimi kullanın: If Settings → Permalinks is set to “Plain”, the address above won't resolve. Use this form instead:

plain permalinks
https://bucagdas.com/?rest_route=/mcp/mcp-adapter-default-server
3

Çalıştığını görünProve it works

Aracınızı yapılandırmadan önce uç noktanın canlı olduğunu doğrulayın. Aşağıdaki komutu terminale yapıştırın; PAROLA yerine 1. adımdaki parolayı yazın. Before configuring any tool, confirm the endpoint is alive. Paste the command below into a terminal, replacing PASSWORD with the one from step 1.

terminal
curl -u "yonetici:PAROLA" \
  -X POST "https://bucagdas.com/wp-json/mcp/mcp-adapter-default-server" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize",
       "params":{"protocolVersion":"2025-06-18","capabilities":{},
                 "clientInfo":{"name":"test","version":"1"}}}'

Şuna benzer bir yanıt gelmelidir:You should get back something like this:

beklenen yanıtexpected response
{"jsonrpc":"2.0","id":1,"result":{"protocolVersion":"2025-06-18",
 "serverInfo":{"name":"MCP Adapter Default Server","version":"v1.0.0"}}}

Bunu gördüyseniz iş bitti sayılır; geri kalanı aracınıza aynı iki bilgiyi vermekten ibaret. 401 aldıysanız kullanıcı adı veya parola yanlıştır. 404 aldıysanız adres yanlıştır ya da adapter etkin değildir. If you see that, the hard part is done; the rest is handing your tool the same two pieces of information. A 401 means the username or password is wrong. A 404 means the address is wrong or the adapter isn't active.

İki tür istemci - hangisi olduğunu bilinTwo kinds of client — know which you have

Araçlar sitenize iki farklı yerden bağlanır ve bu fark, sizin için işe yarayıp yaramayacağını belirler. Aracınızı seçmeden önce bunu okuyun; kurulumdaki hayal kırıklıklarının çoğu buradan çıkar. Tools reach your site from one of two places, and that difference decides whether a given tool will work for you at all. Read this before picking one; most setup frustration starts here.

Yerel istemcilerLocal clients

Satıcının bulutundanFrom the vendor's cloud

Bulut bağlayıcılarıCloud connectors

Claude uygulaması ve claude.ai'daki “Connectors”, ChatGPT'deki “Apps / Developer mode”…The Claude app and claude.ai “Connectors”, ChatGPT's “Apps / Developer mode”…

  • Bağlantıyı Anthropic'in ya da OpenAI'ın sunucuları kurar, sizin bilgisayarınız değil.Anthropic's or OpenAI's servers make the connection, not your computer.

Bunu bilmezseniz vakit kaybedersinizNot knowing this costs you an afternoon

Köprüler kimlik doğrulaması için uygulama parolası kullanır, OAuth değil. Yani bulut bağlayıcı arayüzlerine (Claude uygulamasındaki “Custom connector”, ChatGPT'deki “Create app”) doğrudan uymaz. Masaüstünde Claude kullanıyorsanız çözüm basit: Claude Code yerel bir istemcidir ve doğrudan çalışır. Aynı makinede ikisi de kuruludur. The bridges authenticate with an application password, not OAuth. That means they don't drop straight into the cloud connector interfaces (“Custom connector” in the Claude app, “Create app” in ChatGPT). If you're on the desktop, the fix is easy: Claude Code is a local client and works directly, and it lives on the same machine.

Aynı şey, farklı isimSame thing, different name

Tüm araçlar aynı uç noktaya bağlanır ama yapılandırma dosyasında adresi tutan alanın adı araçtan araca değişir. Bir örneği başka bir araca kopyalayıp “çalışmıyor” demenin en sık sebebi budur. Aşağıdaki tablo hangi aracın hangi adı istediğini gösteriyor. Every tool connects to the same endpoint, but the name of the field that holds the address differs between them. Copying an example from one tool into another and finding it “doesn't work” almost always comes down to this. Here is which tool wants which name.

En sık yapılan hataThe most common mistake

Gemini CLI'da url yazarsanız hata almazsınız; araçlar sessizce görünmez. httpUrl olmak zorunda. Writing url in Gemini CLI produces no error — your tools just silently never appear. It has to be httpUrl.

Araç araç kurulumTool by tool

Her örnekte PAROLA yerine 1. adımda ürettiğiniz uygulama parolasını yazın. Boşlukları silebilir ya da olduğu gibi bırakabilirsiniz. In every example, replace PASSWORD with the application password from step 1. You can strip the spaces or leave them in.

Claude Code yerellocal

Tek komut yeter, dosya düzenlemeniz gerekmez.One command; no file to edit.

terminal
claude mcp add --transport http wordpress \
  "https://bucagdas.com/wp-json/mcp/mcp-adapter-default-server" \
  --header "Authorization: Basic $(printf '%s' 'yonetici:PAROLA' | base64)"

Ardından claude mcp list ile bağlandığını görün. Yeniden başlatmaya gerek yok. Then run claude mcp list to confirm. No restart needed.

VS Code yerellocal

Projenizde .vscode/mcp.json oluşturun. type alanı VS Code'da zorunludur. Create .vscode/mcp.json in your project. The type field is required in VS Code.

.vscode/mcp.json
{
  "servers": {
    "wordpress": {
      "type": "http",
      "url": "https://bucagdas.com/wp-json/mcp/mcp-adapter-default-server",
      "headers": {
        "Authorization": "Basic BASE64_KULLANICI_PAROLA"
      }
    }
  }
}

Claude masaüstü ve webdesktop and web bulutcloud

Claude uygulamasındaki Custom connector alanı yalnız adres ister; uygulama parolası giremezsiniz ve bağlantı Anthropic'in sunucularından kurulur. The Custom connector field in the Claude app takes only an address; there is nowhere to put an application password, and the connection is made from Anthropic's servers.

Dolayısıyla bu köprüler o alana doğrudan uymaz. İki yolunuz var: So these bridges don't drop straight into that field. You have two options:

  • Claude Code'u kullanın. Aynı bilgisayarda, aynı hesapla çalışır, yerel istemcidir ve yukarıdaki tek komutla bağlanır. Çoğu kişi için doğru cevap budur. Use Claude Code. Same machine, same account, and being a local client it connects with the single command above. For most people this is the right answer.
  • Önüne OAuth koyun. Uç noktayı OAuth ile koruyan bir vekil sunucu yazarsanız bağlayıcı alanı çalışır. Bu ayrı bir iştir ve bu sayfanın kapsamı dışındadır. Put OAuth in front of it. A proxy that fronts the endpoint with OAuth will satisfy the connector field. That is a separate piece of work and out of scope here.

ChatGPT bulutcloud

Ayarlar → Security and login → Developer mode açıldıktan sonra Create app ile bir adres eklenir (Plus ve Pro planları). Settings → Security and login → turn on Developer mode, then Create app and paste an address (Plus and Pro plans).

Claude'un bağlayıcılarıyla aynı iki kısıt geçerlidir: siteniz internetten erişilebilir olmalı ve kimlik doğrulama OAuth ya da açık erişim olmalıdır. Uygulama parolası girecek bir alan yoktur. Sitesi yerelde duran veya OAuth kurmak istemeyen biri için ChatGPT bugün uygun bir istemci değildir. The same two constraints as Claude's connectors apply: your site must be reachable from the internet, and authentication must be OAuth or open. There is no field for an application password. For anyone whose site is local, or who doesn't want to stand up OAuth, ChatGPT is not a suitable client today.

Aracınız uzak sunucu desteklemiyorsaIf your tool has no HTTP support

Bazı araçlar yalnız kendi bilgisayarında program çalıştırarak bağlanabilir (buna stdio denir), adres kabul etmez. Bu durumda mcp-remote aradaki çeviriciyi yapar: yerelde çalışır, sizin adınıza uzaktaki uç noktaya gider. Some tools can only connect by launching a program on your own computer (this is called stdio) and won't take an address. mcp-remote is the translator: it runs locally and talks to the remote endpoint on your behalf.

mcpServers
{
  "mcpServers": {
    "wordpress": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://bucagdas.com/wp-json/mcp/mcp-adapter-default-server",
        "--header", "Authorization:Basic BASE64_KULLANICI_PAROLA"
      ]
    }
  }
}
İki nokta üstü üstünden sonra boşluk bırakmayınNo space after the colon

"Authorization: Basic …" değil, "Authorization:Basic …" yazın. Bazı araçlar npx'e argüman geçerken boşlukları kaçırmıyor ve değer bozuluyor. Node.js kurulu olmalıdır. Write "Authorization:Basic …", not "Authorization: Basic …". Some tools fail to escape spaces when invoking npx and the value gets mangled. Node.js must be installed.

Base64 değerini nasıl üretirim?How do I produce the base64 value?

Yukarıdaki örneklerde geçen BASE64_KULLANICI_PAROLA değerini şu komut üretir:This command produces the BASE64_USER_PASSWORD value used in the examples above:

macOS · Linux
printf '%s' 'yonetici:PAROLA' | base64
Windows PowerShell
[Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes('yonetici:PAROLA'))

Bağlandıktan sonra ne yapabilir?What can it do once connected?

Aracınız üç yardımcı araç görür: discover-abilities (neler yapılabileceğini listeler), get-ability-info (birinin ayrıntısını verir) ve execute-ability (çalıştırır). Bunlar kapıdır; asıl işi köprüler yapar. Your tool sees three helpers: discover-abilities (lists what can be done), get-ability-info (details one of them) and execute-ability (runs it). Those are the door; the bridges do the actual work.

Başlamak için aracınıza şunu sorun: “WordPress sitemde neler yapabilirsin?”; listeyi kendisi çıkarır. To get started, ask your tool: “What can you do on my WordPress site?” — it will enumerate the list itself.

Sorun gidermeTroubleshooting

Araç bağlanıyor ama hiç araç görünmüyorIt connects but no tools appear

Üç sık sebep: (1) Gemini CLI'da url yazılmış, httpUrl olmalı. (2) VS Code'da sohbet Agent modunda değil. (3) Sitede etkin bir köprü eklentisi yok; adapter tek başına yapacak iş bulamaz.Three common causes: (1) url written in Gemini CLI where it must be httpUrl. (2) VS Code chat not switched to Agent mode. (3) No bridge plugin active on the site — the adapter alone has nothing to offer.

401 alıyorumresponses

Kullanıcı adı veya uygulama parolası yanlış. Normal giriş parolanızı değil, 1. adımda üretilen parolayı kullandığınızdan emin olun. Parolayı bir daha göremezsiniz; şüphedeyseniz eskisini silip yenisini üretin.The username or application password is wrong. Make sure you're using the password generated in step 1, not your login password. You can't view it again; if in doubt, revoke it and mint a new one.

404 alıyorumresponses

Adres yanlış ya da MCP Adapter etkin değil. Kalıcı bağlantılarınız “Düz” ise ?rest_route= biçimini kullanın.The address is wrong or MCP Adapter isn't active. If your permalinks are set to “Plain”, use the ?rest_route= form.

Yalnızca 7 WooCommerce aracı görüyorumI only see 7 WooCommerce tools

Yanlış uç noktaya bağlanmışsınız. WooCommerce'in kendi ayrı MCP adresi vardır (/wp-json/woocommerce/mcp) ve orada yalnız kendi birkaç fiili bulunur. Bu sayfadaki adres /wp-json/mcp/mcp-adapter-default-server olmalı.You've connected to the wrong endpoint. WooCommerce publishes its own separate MCP address (/wp-json/woocommerce/mcp) carrying only its own handful of abilities. The address on this page must be /wp-json/mcp/mcp-adapter-default-server.

Uygulama Parolaları bölümü yokNo Application Passwords section

Siteniz HTTPS üzerinden çalışmıyor. WordPress bu bölümü yalnız HTTPS'te (ya da yerel geliştirme ortamında) gösterir.Your site isn't on HTTPS. WordPress only shows the section over HTTPS, or in a local development environment.

Hata mesajları anlamsız çıkıyorError messages come back meaningless

“An error occurred while executing the tool.” gibi genel bir mesaj alıyorsanız, sitenizdeki MCP Adapter sürümü eskidir. Büyük eklentiler (örneğin WooCommerce) kendi içlerinde adapter kopyası taşır ve eski olan kopya kazanabilir. Adapter'ı güncelleyin.A generic “An error occurred while executing the tool.” means an old MCP Adapter version is in play. Large plugins (WooCommerce among them) bundle their own copy of the adapter, and the older copy can win. Update the adapter.

GüvenlikSecurity

  • Araç, sizin yetkilerinizle çalışır. Yönetici hesabıyla bağlanırsanız araç da yönetici olur. Yalnız içerik düzenlemesi yapacaksa daha dar yetkili bir kullanıcı açın.The tool acts with your permissions. Connect as an administrator and the tool is an administrator. If it only needs to edit content, create a narrower user for it.
  • Her araca ayrı parola verin. Böylece birini iptal etmek diğerlerini etkilemez. Kullanıcılar → Profil sayfasından tek tek silinebilirler.Give each tool its own password. Revoking one then doesn't disturb the others. They can be deleted individually under Users → Profile.
  • Parolayı yapılandırma dosyasına yazmak zorunda değilsiniz. VS Code'un inputs özelliği ve Codex'in bearer_token_env_var ayarı parolayı dosyanın dışında tutar. Yapılandırma dosyanızı depoya gönderiyorsanız bunu kullanın.You don't have to write the password into the config file. VS Code's inputs feature and Codex's bearer_token_env_var keep it out of the file. Use them if you commit your config.
  • Yıkıcı işlemler onay ister. Silme, toplu değiştirme ve finansal işlemler confirm parametresi olmadan çalışmaz; ajan bunu bilerek geçmek zorundadır.Destructive operations ask first. Deletes, bulk changes and financial operations refuse to run without a confirm parameter, so an agent has to pass it deliberately.
  • Sırlar geri dönmez. Köprüler parola, jeton, API anahtarı ve lisans verisi biçimindeki alanları yanıtlardan temizler.Secrets don't come back out. The bridges redact password-, token-, API-key- and licence-shaped fields from responses.
